What the show keeps coming back to

  • Agent skills are the show's biggest beat, and growing. Skills and plugins were featured 45 times since September, against 17 in April to June. Matt Pocock's skills repo alone came up in 10 episodes.
  • Running many agents at once beats single agents. Orchestration tools like Orca, Paperclip, T3 Code and Hermes Agent recur more than any one coding agent does.
  • "Replace a paid tool" drives the picks. Voice (VoiceStudio, FluidVoice), video generation (MoneyPrinterTurbo, HyperFrames) and self-hosted apps all jumped after the subscription-killer episodes started in August. Video and image tools went from 7 features in spring to 20 since September.
  • Token savers show up often but are early. They were featured 22 times, yet the median one has about 450 stars. Treat them as experiments.
  • Most of the big names are brand new. 25 repos created since April already have 30k+ stars, including REA, Ponytail, Graphify and Caveman. Star counts this high this fast can be inflated, which the show itself discussed.
  • Gaps the new finds fill: local model runtimes, evals and observability, real-time voice agents, workflow automation, home automation and 3D printing, plus open alternatives to the most-covered memory, document and coding-agent repos.

How this was built: every upload on the channel's Videos tab (191) was read through a YouTube data provider. GitHub links in the "Repos featured" lists were taken as given. For 18 episodes (April to early August) that name repos only in chapter titles, each name was matched to GitHub by search; those rows carry a "Matched by name" badge. 10 names could not be matched (Omni, Android Reverse Engineering, Claude Code Context Map, AI Slop Remover, Webwright, Agent Cookie, ElgoLite, Tweaker, Ion Jarvis, Mission Control) and are left out.

Gaps: the show's Resources page keeps each week's full list behind an email sign-up, so it was not used. The 17 oldest uploads (9 to 12 months ago, mostly founder interviews before the repo series began) could not be read before the data provider ran out of credits. Transcripts were not used, so a repo mentioned only in conversation is missing. Shorts and live streams are not included.

Repos that moved since the episode aired show "Linked as" with the old name; 4 linked repos are no longer on GitHub. Summaries are written from each repo's GitHub description, not from testing it.
